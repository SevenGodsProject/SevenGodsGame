# SEVEN GODS

七柱の神々とのカードバトラー。7ラウンド以内に敵を撃破するスコアアタック方式のブラウザゲームです。
React 19 + TypeScript + Phaser 3（Vite）で開発しています（MVP Ver 0.1・8/31完成披露版）。

**本番URL：https://seven-gods-game.vercel.app/**（GitHub連携、pushで自動デプロイ）

---

## SEVEN GODSとは

7柱の神々の中から1柱を選び、その神の専属OTOMOと共に、行動予告を出してくる敵を7ラウンド以内に
撃破することを目指すカードバトラーです。倒しきれなくても、それまでに与えたダメージ分のスコアは残ります
（「負けても記録が残る」設計）。

## 遊び方

1. **神を選ぶ**：7柱の神から1柱を選ぶ。選んだ神によって共鳴発動時の一撃とOTOMOの成長効果が変わる
2. **難易度を選ぶ**：かんたん／ふつう（推奨）／むずかしい
3. **デッキを編成する**：共通カード＋選んだ神の専用カードから20枚（同じカードは基本2枚まで）。おすすめデッキで即開始も可能
4. **バトル**：手札からカードを選び、神力（AP）を使って攻撃・防御・支援・妨害・神託・共鳴カードをプレイする。7ラウンド以内に敵を撃破すれば勝利
5. **勝利／敗北／未撃破**の3状態。勝利後は報酬カードを1枚選べる（次回以降デッキの編成上限が+1）

## 7柱の神と専属OTOMO

神とOTOMOは1柱につき専属1体（七福神モチーフ）。OTOMOは対局中、共鳴発動のたびに
**精霊態 → 受肉態 → 童子**の3形態へ自動で成長します。

| 神 | 専属OTOMO |
| --- | --- |
| 恵比寿 | 鯛丸 |
| 大耀 | 小槌 |
| 蒼毘 | 百勝 |
| 才華 | 琴音 |
| 寿楽 | 寿鹿 |
| 福永 | ハク |
| 笑蓮 | 笑袋 |

バトル開始前のデッキ編成画面で、OTOMOの成長方針を **「守りの絆」**（童子まで育つとHP回復・ブロック強化）
と **「力の絆」**（童子まで育つとカード・神力獲得強化）のどちらかから選べます。方針ごとの童子時効果は
実データから文章化して表示されます。

## 主なゲームシステム

- **神力（AP）**：カードを使うためのコスト。ラウンドが進むほど供給量が増え、余っても次のラウンドには持ち越せない
- **カード60種**：共通カード＋神ごとの専用カード。攻撃／防御／支援／妨害／神託／共鳴の6分類
- **神託**：神力を消費せずに使える3択の後押し（1ゲームに数回・1ラウンド1回まで）
- **共鳴ゲージ**：共鳴カードを使うと貯まり、満タンになると自動で「神の一撃」が発動（神とOTOMOによって内容が変わる）
- **スコアアタック**：ダメージ・コンボ・神力効率・撃破ボーナス・神託／共鳴の内訳でスコアを計算
- **セーブ／続きから**：進行中バトルをカード使用のたびにフルセーブし、いつでも再開できる
- **自己ベスト戦績**：神ごとにベストスコア・勝敗数・最速撃破ラウンドを記録
- **OTOMOとの絆**：対局を重ねるほど育つ、戦闘バランスに影響しない表示専用の親密度Lv

## 対応環境

- PC（デスクトップ幅）、スマホ幅（375px／390px／430px）を実機確認済み。横スクロール・要素はみ出しなし
- 主要ブラウザのモダンバージョンを想定（Vite/React 19標準のブラウザサポート範囲）

## 技術構成

- **フレームワーク**：React 19 + TypeScript + Vite
- **ゲームロジック**（`src/core/`）：Phaser にも React にも依存しない純粋TS。テスト・リプレイ前提で設計
- **UI**（`src/components/`）：React DOM。手札・HPバー・共鳴パネルなど情報密度の高い画面を担当
- **Phaser**（`src/game/`）：現状 `MainScene` のみ。将来のビジュアル演出用に温存
- **設計上の不変ルール**：`src/core/`にPhaser/Reactを持ち込まない、`Math.random()`を使わずシード付き乱数のみ、
  カード効果はハードコードせず`Effect[]`データで表現、調整値は`src/core/data/rules.ts`に集約、
  セーブデータには必ず`version`を持たせる（詳細は`docs/DECISIONS.md`§4）

## 使い方（ローカル起動）

| ツール | 確認コマンド |
| --- | --- |
| Node.js | `node -v` |
| npm | `npm -v` |
| Git | `git --version` |

```bash
npm install     # 初回のみ。必要な部品をダウンロード
npm run dev     # 開発サーバー起動。表示された http://localhost:5173 を開く
npm run build   # 公開用ファイルを dist/ に書き出す
npm run preview # build した結果を確認する
npm run lint    # コードの書き方をチェックする（oxlint）
npm test        # 自動テストを実行する（vitest）
```

開発サーバーは **ファイルを保存した瞬間にブラウザへ反映されます**（HMR）。止めるときはターミナルで `Ctrl + C`。

## 主要フォルダ構成

```
public/
└─ assets/            画像・音声（神7柱・OTOMO7体×3形態・カード60種・BGM/SE 等）
src/
├─ core/              ★ ゲームロジック本体（Phaser/React非依存の純粋TS）
│  ├─ data/             カード・神・OTOMO・敵・神託・ルール数値の定義（rules.ts に調整値を集約）
│  ├─ engine/            バトルの状態遷移（reducer・effects・カード使用・ラウンド進行）
│  ├─ rng/               シード付き乱数
│  └─ types/             GameState等の型定義
├─ components/        ★ React担当 = UI
│  ├─ battle/            バトル画面（手札・HPバー・共鳴パネル・勝敗リザルト等）
│  ├─ setup/             神選択・デッキ構築・戦績・OTOMOとの絆画面
│  └─ feedback/          アプリ内フィードバック機能
├─ hooks/              セーブ／戦績／OTOMO育成記録などlocalStorage連携フック
├─ game/               ★ Phaser担当（現状 MainScene のみ、演出用に温存）
├─ App.tsx             画面全体の土台
└─ main.tsx            アプリの起動地点
```

### 役割分担のルール

- **`src/core/`** … ゲームルール・数値・勝敗判定。Phaser にも React にも依存しない
- **`src/components/`（React）** … 手札・HPバー・スコアなど情報密度の高い画面
- **`src/game/`（Phaser）** … 共鳴発動時のエフェクトなど、将来のビジュアル演出用

仕様・数値の変更履歴と根拠は`docs/DECISIONS.md`、8/31完成披露版の完成状態は`docs/RELEASE_STATUS.md`を参照してください。

## シーンを追加するとき（Phaser側）

1. `src/game/scenes/` に `新しいシーン.ts` を作る
2. `src/game/gameConfig.ts` の `scene: [...]` 配列に追記する
3. 移動するときは `this.scene.start('シーン名')`

## デバッグのヒント

`src/game/gameConfig.ts` の `debug: false` を `true` にすると、当たり判定の枠が緑の線で表示されます。
