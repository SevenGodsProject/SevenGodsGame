# 神7柱の立ち絵 差し替えプロンプト集（ChatGPT/Gemini用）

CEO確認済み（2026-08-07）：既存の神7柱の立ち絵（SGG Creator Kit）を、新しいイラストに**差し替える**方向で進める。

**進捗（2026-08-08）**：7/7完了。`front`・`main`両方を同じ新イラストに差し替え済み。
（笑蓮のみ他6体と絵柄の方向性が異なる旨を一度確認したが、CEOより「採用したい」と回答があったためそのまま採用した）

## 進め方

1. まず「①スタイルの土台」を1回貼って、そのチャット内で②の7体プロンプトを1体ずつ続けて生成するのが理想（同じ会話内で生成すると絵柄がぶれにくい）。品質が落ちるようなら、2〜3体ずつバッチを分けても構わない（`docs/card-art-prompts.md`と同じ考え方）。
2. 使う画像は**戦闘中の立ち絵（`front`）**を想定。神選択画面のサムネイル（`main`）は今回のスコープ外とし、まずは戦闘での見え方を優先する（`main`も差し替えたくなったら追って同じキャラクターデザインで追加生成すればよい）。
3. 生成できたら画像を保存し、パスをClaude Codeに伝えてもらえれば、白背景の透過処理（決定34と同じ手法）・配置は私が行う。

## ① スタイルの土台（最初に1回だけ貼る）

```
これから「SEVEN GODS」という和風カードゲームに登場する、七福神をモチーフにした7柱のキャラクターの
戦闘用立ち絵を、1体ずつ順番に生成してほしい。すべての生成でスタイルを一貫させて。

【スタイル】
和風ファンタジー×アニメ塗り。伝統的な日本の甲冑・装束・和装をベースにしつつ、
現代的にアレンジ（露出の高い際どい衣装にはしない）。凛々しく躍動感のある全身のアクションポーズ、
武器や技のエフェクト（光・水・炎・風など）を伴う。劇画調・写実的・グロテスクな表現にはしない、
少年少女向けカードゲームらしい明るく格好いいトーン。

【構図・技術要件】
- 縦長、全身が入る構図（比率はおよそ2:3〜9:16）
- 背景は真っ白（#FFFFFF）の単色。背景に模様や小物を描かない
  （後で白背景だけを透過処理してキャラクターだけを切り出すため）
- 文字・ロゴ・カード枠などのUI要素は一切描かない、キャラクター単体の1枚絵
- 1回の生成につき1体のみ
```

## ② 7体それぞれのプロンプト

各プロンプトは上記スタイルの直後に続けて貼る。`《 》`内はキャラクター固有の指定。

### 1. 恵比寿（EBISU）
```
《恵比寿》を生成して。
七福神の恵比寿がモチーフ。無邪気で食いしん坊、遊び好きの悪ガキという性格。
少年、赤系＋白の和装（法被風）、大きな鯛を抱えるか肩に担いでいる、釣り竿を持つ。
表情は満面の笑み、常に上機嫌。ポーズは元気よく飛び跳ねるような動き。
```

### 2. 大耀（TAIYO）
```
《大耀》を生成して。
七福神の大黒天がモチーフ。戦いを楽しむ豪快な戦術家、後輩思いの姉御肌という性格。
少女〜若い女性、オレンジ〜赤系の動きやすい戦装束、大きな打出の小槌を模した戦棍（せんこん）を担ぐ。
表情は不敵な笑み、自信満々。ポーズは今まさに一撃を放つ直前のダイナミックな構え。
```

### 3. 蒼毘（SOBI）
```
《蒼毘》を生成して。
七福神の毘沙門天がモチーフ。寡黙で実直な守護者、仲間のためなら一歩も引かない硬派な武人という性格。
青〜藍色を基調にした重厚な甲冑、槍または長刀と盾を構える。
表情は静かで厳しい眼差し。ポーズは仁王立ちで守りを固める、どっしりとした構え。
```

### 4. 才華（SAIKA）
```
《才華》を生成して。
七福神の弁財天がモチーフ。天性のパフォーマー、目立つこと・魅せることが何より好きという性格。
ピンク〜紫系の華やかな衣装、琵琶（びわ）を武器のように構えている、光の音符や花びらが舞う演出。
表情はドヤ顔、決めポーズ。舞台に立つパフォーマーのような華やかな身のこなし。
```

### 5. 寿楽（JURAKU）
```
《寿楽》を生成して。
七福神の寿老人がモチーフ。長い年月を経た悪戯好きの老獪さと、中身は子供のような無邪気さを併せ持つ性格。
見た目は若々しい少年〜青年（老人そのものにはしない）、緑〜金系の着流し風の装束、
鹿の意匠をあしらった杖や首飾りを持つ。表情はニヤリとした悪戯っぽい笑み。ポーズは飄々として軽やか。
```

### 6. 福永（FUKUEI）
```
《福永》を生成して。
七福神の福禄寿がモチーフ。怖いもの知らずの冒険家、幸運は自分から掴みにいく主義という性格。
緑系の軽装の冒険装束、頭に布や小型の兜、腰に剣か杖、背中に荷物や巻物。
表情は不敵で好奇心旺盛な笑み。ポーズは今にも駆け出しそうな前傾姿勢。
```

### 7. 笑蓮（SHOUREN）
```
《笑蓮》を生成して。
七福神の布袋がモチーフ。おおらかで面倒見のいい姉貴分、細かいことは気にせず誰でも受け入れる性格。
紫系のゆったりとした衣装、大きな布袋（ふくろ）を肩に担ぐか傍らに置く、赤みがかった長い髪。
表情は温かく包み込むような笑顔。ポーズはゆったりと余裕のある立ち姿。
```
