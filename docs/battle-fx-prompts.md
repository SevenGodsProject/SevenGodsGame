決定40のCSS演出強化（背景・オーラ・スキルエフェクト）を、CEOが生成した実イラストでさらに上のクオリティに引き上げるためのプロンプト集。`docs/card-art-prompts.md`と同じ運用：ChatGPT（Web版）またはGeminiに貼って生成し、保存したファイルのパスをClaude Codeに伝えてもらえれば、配置・組み込みはこちらで行う。

**進捗（2026-08-07、決定41）**：①戦闘背景・②スキルエフェクト6種とも生成・組み込み完了。
- ①はJPEG化（1672×941→約300KB）して`public/assets/backgrounds/arena.jpg`に配置、`.battle-main`の背景として使用
- ②は1シート（2×3）で生成されたものを6分割・縮小して`public/assets/fx/cast-*.png`に配置、`.cast-flash-art`として`mix-blend-mode:screen`で合成

## ① 戦闘背景（アリーナ）— 最優先・効果が一番大きい

現状はCSSのグラデーションのみ（決定40で色数を増やしたが、実イラストには及ばない）。1枚の背景画像を戦闘画面全体の後ろに敷くだけで、体感クオリティが大きく変わる想定。

```
「SEVEN GODS」という和風カードゲームの戦闘画面の背景に使う、1枚の環境イラストを生成してほしい。

【構成】
七福神モチーフの神々が戦う、雲の上に浮かぶ幻想的な神殿の祭壇。中央〜下部は開けた空間にして、
そこにキャラクターの1枚絵やUIパネルを重ねて配置する前提（構図の主役はキャラクターではなく背景そのもの）。

【スタイル】
和風×ファンタジー×ポップ。金の装飾文様（青海波・雷文等）、淡く光る魔法陣、漂う光の粒子、
夜明けや黄昏どきのような紫〜藍〜金のグラデーションの空。写実的になりすぎず、
既存のカードイラスト同様「和風ポップで迫力がある」トーン。暗く重すぎるダークファンタジーにはしない。

【構図・技術要件】
- 横長、16:9程度（例：1920×1080）
- 中央下寄り〜下部1/3は情報量を減らし、暗めのグラデーションで落ち着かせる
  （UIパネルやキャラクターを重ねて表示するため、そこだけは視認性を優先）
- 文字・ロゴ・UI要素は一切描かない、背景だけの1枚絵
```

## ② スキル使用エフェクト（カード種別ごと・6種）

現状はCSSのアイコンポップ演出（決定40でタイプごとに動きは分けたが、絵そのものはSVGアイコンのまま）。
種別ごとに「弾け方の絵」を用意すれば、カード使用時の迫力が大きく上がる。

**技術要件（全プロンプト共通・必ず伝えること）**：
```
背景は完全な黒（#000000）にしてください。エフェクト本体（光・粒子・軌跡）だけを描き、
黒い部分は透明として扱われる想定です（スクリーン合成）。白背景やグレー背景は使わないでください。
比率は正方形（1:1）、被写体は中央に配置してください。
```
これにより、白背景の透過処理（決定34で手間取った工程）が不要になる — CSSの`mix-blend-mode: screen`で黒を自動的に消せるため。

## ③ 神の立ち絵の追加バリエーション（要検討・保留）

CEOから「選んだ神の画像がシンプル」というフィードバックがあったが、既存の神7柱の立ち絵は
SGG Creator Kit（決定18、商用利用許可済み）のライセンス済み素材であり、勝手に差し替えると
