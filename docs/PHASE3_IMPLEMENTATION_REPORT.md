## 3. Gate 3 の正式判定：WAIVED RISK

**PASSとは表記しない。** 目標 ≤4 に対し実測 7。

内訳（神階Ⅶ normal、対応標本 224試合/カード、有意＝dWin+SE<0 または dWin≤0 かつ dScore<−20）：

| 神 | 導入前 → 実装後 | 残っているカード |
| --- | --- | --- |
| 蒼毘 | **3 → 0** | なし（不動の構え −10.3→−0.4、一喝 −12.5→+0.9、誓いの盾 −12.9→−0.9） |
| 笑蓮 | **4 → 3** | 懐の深さ −3.1、福袋（dWin 0.0・dScore負）、笑って許す −2.7（導入前は −40.6／−41.5／−42.0） |
| 福永 | 0 → 0 | なし |
| 大耀 | 3 → 3 | 豪快な一撃 −3.1、姉御の号令 −4.0、後輩想い −6.2（**Phase 3非対象。前後で完全同一値**） |
| 寿楽 | 1 → 1 | からかい半分 −2.7（**同上**） |
| 恵比寿・才華 | 0 → 0 | なし |
| 合計 | **11 → 7** | Phase 3対象神では 7 → 3 |

WAIVED の理由：
1. 残る7枚のうち4枚（大耀3・寿楽1）は Phase 3 の対象外で、導入前後の値が完全に同一。Phase 3 が悪化させたものではない。
2. Phase 3 対象神では 7→3 に減り、蒼毘は0になった。
3. 笑蓮の残3枚は −2.7〜−3.1pt（導入前は −40台）で、影響は1桁小さい。
4. 対象外4枚まで直すと、FINAL SPEC §15「他神の専用24枚は変更しない」に反する scope creep になる。

→ **Phase 4 backlog へ引き継ぐ**（§5）。

## 6. Human Play QA チェックリスト（10〜15分）

前提：`npm run build && npx vite preview` で起動。難易度は「ふつう」、敵は「試練の影」。各神1戦ずつ（3戦＝約9分）＋カード選択確認（約3分）。

### A. 蒼毘（3〜4分）— 「ブロックを残す」判断が生まれるか
- [ ] 神選択画面に「得意技「反撃の構え」…」が1行で出ており、意味が読んで分かる
- [ ] 戦闘HUDの共鳴パネル上に「得意技 反撃の構え」バッジがある。ブロックがある状態で「発動中」に光る
- [ ] 敵の予告（例：攻撃50）より**多め**にブロックを積んでラウンドを終えると、トーストに「✨ 得意技「反撃の構え」」と敵へのダメージが出る
- [ ] **判断の質**：「予告ぴったり」ではなく「予告より多く積む」ことに意味を感じたか。ブロックが余っても無駄でないと感じたか
- [ ] 不動の構え・一喝を使うとき、条件行（⚡ 金色＝今使えば追加が出る／＋ 灰色＝条件未達）が判断材料になったか

### B. 笑蓮（3〜4分）— 「回復してから殴る」判断が生まれるか
- [ ] 神選択画面に「得意技「無傷の慈愛」HPが8割以上のとき、攻撃カードのダメージ+50%」が出ている
- [ ] HP満タン付近で攻撃カードを使うと、通常より大きいダメージが出る（トーストに得意技が出る）
- [ ] HPが8割を切った後、**回復してから殴る**か、そのまま殴るかで迷いが生まれたか
- [ ] 回復カード（福袋・笑って許す・息吹）が「ただのHP回復」ではなく「次の一撃を強くする準備」に感じられたか
- [ ] 福袋をHP半分以下で使ったとき、共鳴+2が入ることに気づけたか

### C. 福永（3〜4分）— 「危険を維持する」リスク・リターンを感じるか
- [ ] 神選択画面に「得意技「大勝負」HPが半分以下のとき、攻撃カードのダメージ+50%」が出ている
- [ ] HPが半分以下のとき、HUDバッジが「発動中」に光り、攻撃が大きくなる
- [ ] **判断の質**：「回復して安全になる」か「低HPを維持して押し切る」かで迷ったか。迷いが緊張感になっているか、単に事故死しただけか
- [ ] 神技評価「大勝負」（結果画面のグレード）と得意技「大勝負」を混同しなかったか

### D. カード選択（2〜3分）
- [ ] デッキ構築画面で 不動の構え／一喝／福袋／笑って許す に条件行（＋…）が出ている
- [ ] 不動の構え が 鉄壁の構え の下位互換に見えないか（ブロック130＋条件付き60ダメージとして理解できるか）
- [ ] 一喝 が 呪縛 の上位版として理解できるか
- [ ] 勝利後の報酬3択に上記カードが出た場合、条件行が読める
- [ ] 条件の言葉（予告以上のブロック／敵の予告が100以上／HPが半分以下）がスマホで一読できる長さか

### E. 全体（1〜2分）
- [ ] カード説明が長すぎない（本体＋条件で2行以内に収まっている）
- [ ] 1戦が3分前後で終わる（得意技で戦闘が長くなっていない）
- [ ] 得意技を持たない4神（恵比寿・大耀・才華・寿楽）で、以前と違和感なく遊べる
- [ ] **総合**：神を変えたとき「考え方が変わった」と感じるか。特に蒼毘・笑蓮・福永で、以前と違う遊び方をしたか

### 記録してほしいこと
- 上記で「No」だった項目と、そのときの状況（神・ラウンド・HP・敵）
- 「説明が分からなかった」語句があればその語句
- 3神それぞれで一番印象に残った判断の瞬間（あれば）
