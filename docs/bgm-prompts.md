# BGM・音楽アセット生成プロンプト集

決定49の実プレイ評価で指摘した「BGMが1曲も無い（`sound.ts`はOscillatorNodeによる効果音の合成のみ、音楽トラックは未着手）」への対応。`docs/card-art-prompts.md`・`docs/god-portrait-prompts.md`・`docs/battle-fx-prompts.md`と同じ運用：このドキュメントのプロンプトを生成AIに貼って作った音源ファイルを、保存先のパスと一緒にClaude Codeに伝えてもらえれば、組み込み（`<audio>`要素の追加、ミュートボタンとの連動、ループ設定）はこちらで行う。

**ツールについての注意（これまでのイラスト系プロンプト集との違い）**：ChatGPT・Geminiの標準的なテキスト対話では音楽ファイルそのものは生成できない。音楽生成には専用のAIツールが必要で、2026年8月時点で代表的なものは以下（いずれもテキストプロンプトで曲を生成する方式なので、下記のプロンプトはそのまま貼って使える想定）：

- **Suno**（suno.com）— 曲名・歌詞なしのインストゥルメンタル指定が可能。無料枠あり
- **Udio**（udio.com）— 同上、無料枠あり
- **ElevenLabs**（elevenlabs.io）の Sound Effects 機能 — 短い環境音・ジングル向き

CEOがどれかのアカウントを持っていない場合、この項目は一旦保留にして他のタスクを進めても問題ない（§3-2の他の項目と同じく、CEOの外部ツール利用を前提とするため）。

---

## 技術要件（全プロンプト共通）

- **インストゥルメンタルのみ・歌詞なし**（`lyrics: none` / instrumental指定）。ボーカルが入るとループ時に違和感が出やすいため
- **ループ再生を前提**とするため、**イントロなしで最初から主旋律が始まる曲**が望ましい（曲の頭に長い静寂やフェードインがあると、ループのつなぎ目で不自然な間ができる）
- 書き出しはmp3（128kbps程度で十分、`public/assets/bgm/`に配置予定。決定41の背景画像が約300KBに収まっている水準に合わせ、1曲あたり2〜3MB程度を目安に）
- 曲の長さは1〜2分のループ素材で十分（`<audio loop>`で繰り返し再生する前提）

## ① ホーム・神選択・デッキ構築画面 用 BGM（最優先）

起動して最初に流れる曲。プレイヤーがゲームの世界観に入る最初の音なので、①を1曲だけ作るなら最優先はこれ。

```
和風ファンタジーのカードバトルゲーム「SEVEN GODS」（七福神モチーフの神々と戦うカードゲーム）の、
タイトル画面・キャラクター選択画面用のBGMを作ってほしい。

【ムード】
和風ポップで温かく、期待感のある雰囲気。壮大すぎず、暗すぎない。
「これから神様と一緒に冒険が始まる」というワクワク感。

【楽器編成】
琴・尺八・太鼓などの和楽器を、シンセパッドやポップなビートと組み合わせたモダン和風。
既存のカードゲーム音楽（例：和風×アップテンポなポップス）を参考にした質感。

【技術要件】
インストゥルメンタルのみ（歌詞・ボーカルなし）。イントロの静寂は最小限にし、
曲の頭から主旋律が始まるようにしてください（ループ再生前提のため）。
テンポは中〜ややアップテンポ（BPM100〜120程度）。長さ1〜2分。
```

## ② 戦闘画面 用 BGM

7ラウンドの緊張感を支える曲。ホームBGMより少しテンポが速く、しかし焦らせすぎない程度。

```
上記と同じ「SEVEN GODS」の戦闘画面（カードバトル中）用のBGMを作ってほしい。

【ムード】
緊張感がありつつも爽快感がある、和風バトルミュージック。7ラウンドで決着する
テンポの速いカードゲームなので、長時間聴いても疲れない適度な緊張感にする
（重々しいダークファンタジー調にはしない。①のホーム画面BGMと世界観は共通させつつ、
よりビートが強く前のめりな曲調に）。

【楽器編成】
和太鼓のビートを主軸に、琴・尺八のフレーズ、シンセの厚みを加えたモダン和風バトル曲。

【技術要件】
インストゥルメンタルのみ（歌詞・ボーカルなし）。イントロの静寂は最小限にし、
曲の頭から始まるようにしてください（ループ再生前提のため）。
テンポはアップテンポ（BPM130〜150程度）。長さ1〜2分。
```

## ③ 決着ジングル（勝利・敗北、それぞれ5〜10秒）

`GameOverOverlay`が表示される瞬間に一度だけ鳴らす短い曲。ループ不要、むしろ短く終わることが重要。

### 勝利ジングル
```
上記と同じ「SEVEN GODS」の、バトル勝利時に一度だけ鳴らす短いジングルを作ってほしい。
華やかで達成感のある和風ファンタジー調、5〜10秒程度。琴や鈴の音を使った、
きらびやかで気持ちの良い締めくくり。インストゥルメンタルのみ、ループ不要（1回で完結する曲）。
```

### 敗北ジングル
```
上記と同じ「SEVEN GODS」の、バトル敗北時（HP0）に一度だけ鳴らす短いジングルを作ってほしい。
悲壮になりすぎない、和風の「残念だったが、また挑もう」と思えるトーン、5〜10秒程度。
インストゥルメンタルのみ、ループ不要（1回で完結する曲）。
```

## 組み込み方針（実装時のメモ）

- `public/assets/bgm/`に配置し、`src/components/battle/sound.ts`（決定22の効果音合成と同じファイル、もしくは隣接する新規`bgm.ts`）に`<audio>`ベースの再生ロジックを追加する想定
- 既存の`muted`（`App.tsx`のミュートボタン、決定45でヘッダーに一本化）と連動させ、ミュート時はBGMも止める
- 画面遷移（ホーム/神選択/デッキ構築 ⇄ 戦闘）に合わせてトラックを切り替え、決着ジングルは効果音と同様に1回だけ再生してBGMをフェードで戻す
- 生成物が「思っていた曲調と違う」場合は、決定41の笑蓮立ち絵と同じ扱い（一旦保留してCEOに確認）で進める
