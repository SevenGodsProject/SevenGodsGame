# カードイラスト生成プロンプト集（ChatGPT用）

決定30で導入したSVGアイコンを実写イラストに差し替えるための、ChatGPT（Web版）に貼るプロンプト集。

**進捗（2026-08-06確認）**：`public/assets/cards/`実ファイルで突き合わせ済み。
- ✅ 完了：バッチ1〜7（攻撃・防御・共鳴・支援・妨害）、バッチ7-2（神託）＝共通カード28/28枚（全完了）
- ✅ 完了：バッチ8〜14（恵比寿・大耀・蒼毘・才華・寿楽・福永・笑蓮）＝神専用28/28枚（全完了）
- **56/56枚、全カードのイラスト対応が完了（決定37）**

**方向性（2026-08-05に実物サンプルで確定）**：ちびキャラ（デフォルメ）が種別カラーの鮮やかな単色背景＋和柄（青海波・麻の葉など）＋金の装飾線の中でアクションを取る、和風ポップなスタイル。背景も含めて丸ごとカード全体の絵として使う方針のため、決定32・34のような白/黒背景の透過処理は不要（好都合、工程が1つ減る）。

進め方：①を最初に1回だけ貼る → ②以降のバッチを1つずつ、新しいチャットまたは同じチャット内で順に貼る（1回につき1バッチ、4枚ずつ）。
生成できたら画像を保存し、パスをClaude Codeに伝える。切り出し・リサイズ・`public/assets/cards/`への配置は私が行う。

## ① スタイルの土台（最初に1回だけ貼る）

```
これから「SEVEN GODS」というカードゲームのカードイラストを、複数バッチに分けて生成してほしい。
以降のすべてのバッチで、以下のスタイルを一貫させて。

【参考イメージ】
ちびキャラ（2〜3頭身のデフォルメ）が、刀や光の軌跡を伴うダイナミックなアクションポーズを取っている構図。
表情は生き生きと（決意・不敵な笑み等）。日本の伝統文様（青海波・麻の葉・七宝つなぎ等）を背景に薄く敷き、
金の細い装飾線・光の粒子・和紙のような質感を加える。全体として「和風×ポップ×迫力」。
写実的・劇画調・ダークで重い雰囲気（血しぶき・怖い表情の老人等）にはしないこと。

【構図】
- 縦長、カード1枚分の絵（比率はおよそ3:4）
- 背景は種別ごとのテーマカラーを基調にした単色〜グラデーション（下記参照）。黒ベタにはしない
- キャラクターと効果の光・エフェクトを画面いっぱいに大きく配置。文字やUI要素、カード枠は描かない
- 背景の透過処理はしないので、そのまま1枚の完成したイラストとして仕上げて（余白の少ない構図でOK）

【出力】
1回のバッチで、指定した4枚のカードをシート状（2×2または横並び）に並べて生成して。カード名も画像内に小さく入れず、絵だけでよい。
```

## ② バッチ一覧（種別ごと・神ごと）

各バッチは下記フォーマットで貼る：

```
上記スタイルで、以下4枚のカードイラストを1シートで生成して。

種別: {種別}／テーマカラー: {色}

1. {カード名} — {効果}
2. {カード名} — {効果}
3. {カード名} — {効果}
4. {カード名} — {効果}
```

種別ごとのテーマカラー（`cardStyle.ts`の`TYPE_STYLE`準拠）：
攻撃=赤系(#e5484d)／防御=青系(#4d88e5)／共鳴=金/黄系(#ffd166)／支援=緑系(#4dbd74)／妨害=紫系(#9b59b6)／神託=ピンク系(#ff6ec7)

## 注意点

- 神専用カードは、その神のビジュアル（`public/assets/gods/<id>/`）や性格を軽く連想させる程度でよい。神の顔そのものを描く必要はない（カードは効果のシンボル、神ではない）
- 56枚を一気に頼むと破綻しやすいので、1バッチ＝1回のやり取りが安定（決定32の「敵7体を1シートで作った」実績と同じペース感）
- 生成物を渡すときは、いつも通り保存先パス（PowerShellの`& '...'`形式でもOK）を伝えるだけで良い
- 背景も含めて完成イラストとして使うため、現在の`cardStyle.ts`のタイプ別グラデーション背景は今後カード絵に置き換わる想定（実装はイラストが揃ってから別途対応）
