## 1. Measurement Problem

Step 2 まで使っていたカード優先度指標「使用率（手札に来たうち使った割合）」は、探索AIが **手札に来た札をAPの許すかぎりほぼ全て使う**（75〜98%）ため天井に張り付き、神ごとの差を測れなかった。ランダムデッキ回帰による deck inclusion value（dWin）も 220〜300デッキでは ±7pt のノイズを持ち、報酬一致率が条件だけで 44%↔20% と揺れた。

必要なのは「その神にとって、そのカードは他のカードよりどれだけ価値があるか」を**低ノイズ**で測る指標。

---

## 2. New Metric：God × Card Marginal Value（対応seed・1枚差し替え法）

- 神 g のおすすめデッキ20枚から、価値が最も低い共通カード1枚（filler：全神で「予言」が選ばれた）を抜いた19枚を base19 とする。
- 候補カード c（その神が使える36種）について、**c を20枚目に入れたデッキ**を、base19＋filler（＝現行おすすめデッキそのもの）と **同じseed・同じ敵の対（224試合）** で比較する。
  - c が既に2枚入っている場合（専用カード等）は「1枚抜いて filler を2枚目として入れる」で測り、符号を反転して「持っている価値」に換算する。
- 出力：ΔWin（pt）とそのSE（対応差 d_i∈{−1,0,+1} から直接算出）、ΔScore、合成価値 ＝ ΔWin ＋ ΔScore/50。
- 神間比較には神ごとに平均を引いた「中心化価値」を使い、順位相関（Spearman）を取る。

この方法の利点：同じ試合展開に1枚だけ差を入れるため、ランダムデッキ回帰より分散が1桁小さい（SE 1.5〜4pt）。欠点：値は「おすすめデッキという文脈での限界価値」であり、デッキ全体を組み替えた場合の価値ではない。

追加で、報酬3択EV（共通カードからランダム3枚を提示し、神別最良を選んだときの一致率と、合意札を選んだ場合に失う価値）、上位8共通カードの重なり、分岐札（ある神で上位8・別の神で下位8）を算出した。

## 7. Negative Exclusive Cards

Step 1 の負価値16枚を推奨案（Ⅶ normal、対応標本）で再判定：

| 判定 | 枚数 | カード |
| --- | --- | --- |
| 正に転じた（合成>0） | 8 | 不動の構え・一喝・誓いの盾・反撃の刃（蒼毘）、幸運の女神・不屈の一歩（福永）、一心不乱・後輩想い（大耀） |
| ほぼ0（±1.5） | 3 | 悪戯・長生きの知恵・からかい半分（寿楽） |
| 依然負（合成<0） | 5 | **福袋 −3.4、笑って許す −8.1、懐の深さ −7.9（笑蓮）**、福授け −2.1（恵比寿）、独奏・喝采は正へ |
| 新たに負（Step 1 では正） | 2 | おおらかな一打 −4.3（笑蓮）、豪快な一撃 −0.3（大耀、SE内） |

専用28枚全体：負価値 17→10、**統計的に有意な負価値は 12→4 で、その4枚は全て笑蓮**（福袋・おおらかな一打・懐の深さ・笑って許す。ΔWin −2.2〜−6.2、ΔScore −35〜−103）。

原因：笑蓮の Passive は「満タンで殴る」を報酬するため、AIは回復札・ブロック札より「引いて殴る」（予言）を選ぶ。回復札が価値を持つのは HP を削られた後だが、その局面では「回復して満タンに戻す」より「そのまま殴る」方が速い。**Passive と専用札の噛み合いが未完成**で、FINAL SPEC で（a）Passive の閾値を「満タン」から「HP 80%以上」等へ緩める、（b）福袋・笑って許すの条件を `lowHp` から「回復で満タンに達したら〜」へ変える、のどちらかを simulation で決める必要がある（第2波、4枚以内）。

**判定：RISK。**

| Q1 God間のカードranking相関は下がるか | **No**（0.64→0.69、stress 0.56→0.61） |

## 11. FINAL SPEC GO / NO-GO

**判定：FINAL SPEC v0.1 作成へ GO（条件付き）。Production実装は NO-GO 継続。Minimal Change Set の再設計は行わない（FAIL ではないため）。**

FINAL SPEC v0.1 に含める条件（AI側で simulation して確定、CEO判断不要）：
1. **笑蓮の噛み合い調整（第2波・4枚以内）**：Passive「満タン」閾値の緩和（HP 80%以上 等）または 福袋・笑って許すの条件変更（`lowHp` → 「回復で満タンに達したら」）を pilot し、笑蓮専用4枚の有意負価値 4→≤1 を目標にする。
2. **蒼毘 Passive の係数**：残ブロック「半分」→「等倍」または「獲得時に即時半分」を pilot し、共通ブロック札（鉄壁の構え・守護）が蒼毘だけ正になるかを確認する（共通カード順位に神差を作れる唯一の経路）。効果が無ければ現行案のまま確定。
3. **共通カード優先度**は Phase 3 の達成目標から外し、**報酬提示の神別重み（Phase 4）**へ送ることを FINAL SPEC に明記する。
4. 本Step の対応標本法（`marginal.audit.ts`）を FINAL SPEC の Failure Gate 計測器として採用し、使用率指標は廃止する。

CEO判断が必要な事項：**なし**。
