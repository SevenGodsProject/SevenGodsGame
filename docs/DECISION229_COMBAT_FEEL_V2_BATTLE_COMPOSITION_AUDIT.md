### 14-2. 原因
- **素材セットの向きの慣習が「画面の左向き」**（神 5／7、敵 4／7 が左、残りは正面寄り）。SP（と PC）は敵が左・神が右に立つため、**左向きの神は敵を向くが、左向きの敵は神に背を向ける**＝「同じ左を向いている」
- 既存 CSS に `scaleX(-1)` などの反転は 0 件（原画の向きのまま表示していた）
- 攻撃の向き：突進・突き・ノックバックは `--atk-x`（敵 +1＝右へ・神 −1＝左へ）で既に相手の方向。**動きは向き合っているのに、絵が向き合っていない**
- 窮屈（Q5）：神と OTOMO の絵の間隔が最小 3〜4px（v1）。OTOMO は主役ではないのに神と同じ床幅を取っていた

### 14-3. 一般化
**敵だけを一律に左右反転**すれば、7 体すべてが右（神の方）を向く（左向き 4 体は右向きに、正面 3 体は鏡像になるだけ）。敵の原画には文字・紋章がないため反転で不自然になるものは 0。神は反転しない（左向き＝既に敵の方。福永の兜の文字も守る）。個別の例外指定は不要＝`if (enemy === …)` のような素材ごとの指定なしで成立する。

### 14-4. 反転の安全性（コードで確認）
| 動き・演出 | 付いている要素 | 反転の影響 |
|---|---|---|
| 待機の呼吸 | `.enemy-avatar`（translateY・scale） | 上下のみ＝影響なし |
| 単発の突進（enemy-lunge*） | `.enemy-avatar`（`--atk-x` で向き） | 反転で逆向きになる → **この要素だけ `--atk-x: -1`** で打ち消す |
| 連撃の突進（enemy-lunge-multi-*） | `.enemy-avatar-wrap`（外側・固定 +x） | 反転しない＝影響なし |
| 被弾（juice-stop・hit-shake） | `.enemy-reaction`（外側） | 影響なし |
| 撃破（enemy-defeat） | `.enemy-collapse`（外側） | 影響なし |
| 斬撃・数字・金リング・撃破リング | `.enemy-hit-layer`（兄弟） | 反転しない＝着弾位置は不変 |
| 溜め・後半強化 | `.enemy-avatar`（filter・box-shadow のみ） | 影響なし |
反転は `transform` ではなく独立した `scale` プロパティ（アニメーションの transform と合成される）。
