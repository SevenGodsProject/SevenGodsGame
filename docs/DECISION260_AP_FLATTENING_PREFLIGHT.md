## 3. 判定の根拠【AI 判断】

1. **通常で randomRO − reader が動かない**：5 案とも −3pt 未満。AP 後半の削減は「余り AP」を削るだけで、R1〜R5 の出す枚数は不変。「全部出せる」（HDD 監査の Root Cause）は正しいが、**出せるかどうかは勝敗に影響していない**＝勝敗を決めるのは加護の判断（randomRO＝reader の構造）であり、AP 制約は答えの幅を狭めない
2. **価値が戻る面は難化の副作用**：Hard／Daily／神階で randomRO が落ちるのは reader も落ちる局面（未撃破↑・R5〜R6 で殴り切れない）。託宣の使い方・盾率は不変で「解き方」は変わっていない＝CEO 禁止事項「HP sponge 化」「Hard／神階を理不尽化しない」に抵触
3. **R4 を触る A4 は決定246 の峰（R4）に直撃**：通常 naive 敗北 30.8％・reader−naive 29.2pt＝Combat Tension v1 の帯（naive 敗北 15〜16％・読む価値 15〜16pt）を大きく外れ、Hard reader 89.4・Ⅶ猛威 44.7
4. **near candidate を追加しない理由**：R5 以降の削減（A1／A2／A3）は通常に無反応、R4 以前の削減（A4）は保護に抵触。中間（例 `[2,3,4,5,5,5,6]`）は A1 と A3 の間に入ることが §2 の単調性から読める（A3 ⊂ A1 ⊂ A2 の順で通常 −1.8／−0.3／−0.4・Hard reader 86.8／93.3／94.6）。無制限探索禁止の指示に従い打ち切る
