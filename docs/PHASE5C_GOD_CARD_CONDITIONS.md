# Phase 5-C — 神専用カードによる神格差別化：縮小パイロット（決定159・PASS / CLOSE）

Phase 5-A（共通カードの条件）で「1ラウンド内の順番判断」は生まれたが、神ごとの行動差は広がらなかった。
本監査は、**神専用カード側に条件付き追加効果（`bonus`）を置く**ことで「この神だから、この順番・この盤面を狙う」が
作れるかを、本番コードを変えずに比較した記録。対象は福永・大耀・蒼毘の3神（§0〜§9 は設計監査時点の記録）。
成果物はこの文書と `scripts/phase5c-god-cards/godCardsAudit.test.ts`（`P5C_RUN=1`）。

どのカードに条件を付けると「その神らしい判断」が増えるか：
* **大耀**：順番が意味を持つのは「号令→攻撃」と「共鳴を積む→豪快」。条件 `charged`（共鳴4以上・使う前に判定）を号令と豪快に置くと、「今すぐ豪快を撃つか、先に共振・一心不乱で4まで積んでから号令→豪快で吐き出すか」の判断になる。神技「爆発」（1Rの最大ダメージ）とも同じ方向

### 福永に条件を付けても判断が変わらない理由
低HP圏では、方策の選択が「危険なら守る／回復する、そうでなければ得意技の乗った攻撃」で**既に決まっている**。lowHp の bonus は、その決まった選択の上に数字が乗るだけで、比較対象を変えない（選択変更 0.01〜0.05/戦）。
変えるほど大きい bonus（F4 の共鳴+2）にすると、神の一撃が +23% 増えて勝率が +10pt 動く。「HPを回復するか低HPを維持して攻めるか」の迷いは**得意技が既に作っている**（低HP攻撃 1.5回/戦は他神の2〜30倍）ので、カード側に重ねる必要が薄い。

### 4-4. 種別内訳（基準5）は動かない
PILOT でも3神の種別内訳は ±1pt。専用 bonus は「同じカードをいつ・どの順で出すか」を変えるが、「どの種別を何枚使うか」はデッキ構成で決まる。
福永と大耀の差（8pt）を広げるには、両神を v4 手組みデッキ（蒼毘・寿楽と同じ方式）にして共通12枚の中身を変える必要がある。これはカード条件ではなくデッキデータの変更で、別Phaseの範囲。

## 6. Known Risks

1. **福永は今回変更なし**。福永の神格差は得意技に依存したままで、「専用札で判断が変わる」設計にはなっていない。lowHp 以外の条件（combo・charged）で福永らしさを作るには、自傷札の性質を使う新条件（例：このラウンドに自傷した）が要り、新条件の追加は本Phaseの原則に反するため見送った
2. **大耀の bonus は cardaware でしか価値が出ない**。固定方策（blind）は条件を見ないので、大耀 +2〜+3pt は「豪快をたまたま共鳴4以上で撃った」分。予告・条件を読まないプレイヤーには効果が薄い（Phase 5-A と同じ性質）
3. **姉御の号令の bonus は攻撃バフの重ね**（+30 の上に +30・1ラウンド）。`buff` の rounds:1 が「このラウンドだけ」になることを実装時に `buffs.ts` で確認する（既存の号令は rounds:2）
4. 蒼毘は4枚中3枚に bonus が付く。「専用札は全部条件付き」に近づくので、これ以上は足さない
5. 神階Ⅶ overall は 54〜55 で帯の上端。Phase 5-C の後に難易度を触る Phase を挟まないなら、次に緩める変更はできない
6. 種別内訳の神差（基準5）は本案では達成できない。達成するにはデッキ構成の Phase が要る
