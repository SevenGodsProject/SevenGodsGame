Phase 5-A（決定154）で共通16枚に条件付き追加効果を入れた結果、神階Ⅶが 49%→67% へ緩んだ。
本Phaseは **カード側を一切触らず**、神階ラダーに由来する敵側の既存 modifier だけを最小限動かして、
Phase 5-A 前の難易度カーブへ戻す。

## 1. 変更した神階modifier（`RULES.stakes`、3値のみ）

| 値 | 変更前 | 変更後 | 効く段 |
|---|---|---|---|
| `lateRoundAtkMul`（R5以降の敵攻撃倍率） | 1.2 | **1.3** | Ⅰ〜Ⅶ |
| `enemyAtkStep`（敵攻撃の段あたり倍率） | 1.1 | **1.15** | Ⅰ〜Ⅶ（Ⅶ「猛威」はさらに×） |
| `enemyHpStep`（敵HPの段あたり倍率） | 1.1 | **1.15** | Ⅲ〜Ⅶ（Ⅶ「巨躯」はさらに×） |

触っていないもの：`blockEfficiency` `healEfficiency` `specialMul` `divinationCount` `initialHandMinus`、
カード60枚、神Passive、OTOMO、Enemy Intent、神託、報酬、スコア式、BURST、Daily、Ranking、`saveVersion`（9のまま）。
神階の説明文（`STAKE_LEVELS`）は `RULES.stakes` から自動導出しているため「敵HP+15%」「敵の攻撃+15%」「R5以降 +30%」に自動で追従する。

### 変更理由

* Phase 5-A の成分分離（決定154）で、勝率を押し上げたのは**テンポ系の追加効果が神の一撃を1回多く回すこと**だと分かっている。
  カード側を弱めるのは禁止なので、敵側で「その1回ぶん」を吸収する。
* **HP+ と ATK+ を同量だけ同時に**積むのは、決定126 の「防御神にはHP+が、攻撃神にはATK+が効く」という
  公平性の原則を崩さないため。ATK だけ（`atk120_late130`）でも Ⅶ 49% に届くが、BURST −12%・選択差 −10% と
  Phase 5-A の面白さ側の指標が落ちるので不採用。
* `lateRoundAtkMul` は R5 以降だけに効くため、「序盤は組み立て、終盤は受けの判断」という Phase 5-A の
  リズムを壊さずに難易度を足せる。
