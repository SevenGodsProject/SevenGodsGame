## 4. 次テーマ：共通カードへの「条件・連携」導入 — 最小仕様案

### 4-1. 何を変えるか（1行）

**共通カードの主力16枚に、`bonus`（条件が成立したときだけ出る追加効果）を付ける。本体の数値は変えない。**

### 4-2. なぜこれが9項目に効くか

| 監査項目 | 効き方 |
|---|---|
| カードを選ぶ意味 | 「今この盤面で条件が立つ札」が毎ラウンド変わる。手札の強調（既存 `previewBonusTrigger`）で見える |
| 共通カードが似すぎ | 同じ「120ダメージ」でも条件が違えば別の札になる |
| 7神の差 | 条件が神の型と噛む（蒼毘＝予告以上のブロック、才華＝連携、恵比寿＝共鳴、寿楽＝弱体中） |
| Intent を見る必要 | 条件①は予告を見ないと立たない |
| 1戦目から | R1 から「条件を立てる順番」を考える手が生まれる |
| 敗北→次は | 「条件を立てられなかった」が敗因として見える |
| 勝利→別構成 | 条件の組み合わせ＝デッキの個性になる |
| 手札事故 | 攻撃札ゼロでも「条件札で盤面を作る」手が残る |
| Daily 再挑戦 | 同じ Seed で**別の条件ルート**を試す動機 |

### 4-3. 条件は4種だけ（既存2＋新規2）

| 条件 | 判定 | 既存／新規 | 主に付ける型 |
|---|---|---|---|
| `blocked` | このラウンドのブロックが敵の予告以上 | **既存** | 防御・反撃系 |
| `enemyBig` | 敵の予告が大技（閾値10） | **既存** | 妨害・回復 |
| `combo` | このラウンド **2枚目以降** に使った | **新規**（`state.cardsPlayedThisRound` を見るだけ） | 攻撃・支援 |
| `charged` | 共鳴ゲージが **4以上** | **新規**（`state.player.resonance` を見るだけ） | 共鳴・攻撃 |

`lowHp` は福永の型に寄るので共通には使わない。5種目は作らない（判断が散る）。

どの条件も**単独では弱く、並べると強い**。本体を変えないので、条件を立てられない手でも今と同じ強さ＝下振れしない。

- カード本体の数値・コスト・枚数・デッキ規則

### 4-7. リスクと緩和

| リスク | 緩和 |
|---|---|
| 強くなりすぎて難易度カーブが崩れる | 本体不変＋追加は小さめ。STAKE-01 で神階Ⅰ〜Ⅶの勝率が **±5pt 以内**を合格線に |
| 特定の神だけ得をする | cardpref で神別の種別比率を再計測。**神間の攻撃比率の幅が今の 6pt → 12pt 以上に広がる**ことを狙い、1神だけ勝率が +8pt 超なら値を下げる |
| 条件が読めず初心者が混乱 | 条件は4種固定・手札の強調で「今立つ」を見せる（既存UI）・カード本文に1行で書く |
| Daily の day-lock | 0:00 deploy。当日の進行中 run は voided で枠返還（既存仕様） |

### 4-8. 受入基準

1. 16枚すべてに `bonus` が付き、`cardTextScale.test` と golden replay が通る
2. `balanceSim` STAKE-01：全神・全神階で勝率変化 **±5pt 以内**、かつ神階Ⅶ overall が 45〜55%
3. cardpref：神別「攻撃」比率の最大−最小が **12pt 以上**（今 6pt）＝神で手が変わる
4. 実プレイ：ふつう×3戦で「条件が立った回数」が **1戦あたり 4回以上**、うち1回以上は**予告を見て手を変えた**結果であること
5. 手札に攻撃札ゼロのラウンドでも、条件札で **敵HP・ブロック・共鳴のどれかを動かせる**
6. 1戦の所要が **5分を超えない**（テンポを壊さない）
7. モバイル縦画面で手札の強調が判別できる
