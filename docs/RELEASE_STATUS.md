- **バトル演出・サウンド**：攻撃モーション・被弾エフェクト・数値ポップアップ・カードイラスト全60種（決定84で新規4枚追加）・共鳴発動演出・OTOMO進化バナー（決定82・82フォローアップ）

### ステップ3：本番当日、ステップ2以降は絶対にlocalStorageを削除しない
ステップ2で仕込んだバトルセーブが消えるため。ミュート操作・画面遷移・カード使用などの通常操作はlocalStorageの`battleSave`を上書きしないため問題ない（`saveBattle`は進行中の対局のあらゆる操作（カード使用・ラウンド終了・託宣選択等）のたびに同じ対局の状態を更新するのみ）。

- [ ] **【最重要・要注意】ホーム画面に戻った場合、「神を選ぶ」ボタンを絶対に押さない。** このボタンは確認ダイアログ無しで即座に`clearBattleSave()`を実行し、仕込んだバトルセーブを消去する（`GameFlow.tsx`の`onStartFresh`）。しかも「続きから」ボタンより視覚的に目立つ金色グラデーションのデザインで、隣に並んで配置されているため誤タップのリスクが高い（2026-08-17、夜間調査で判明）。本番当日、ホーム画面が表示された場合は必ず**「続きから（恵比寿・ラウンドN）」**を押すこと
