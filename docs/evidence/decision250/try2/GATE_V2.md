# 決定250 Gate v2（Try2 の生成前に固定・2026-09-29）

- 目的：Try1 の Gate は原本 0〜0.4s を評価し、配信した候補 D（1.10〜4.71s）と 1 frame も重ならなかった。Gate v2 は **実際にゲームへ配信する候補区間そのもの** を、単純 MAE ではなく semantic identity で判定する
- 実装：`gate_v2.mjs`（sharp のみ・非生成）。参照＝CEO 承認の入力板（`front_640.webp` 由来・sha256 `57eabb31…`）。keyvisual は生成入力にも機械参照にも使わず、**目視比較（円クロップ）**でのみ扱う
- 判定対象：①原本全 frame（傾向の把握）②配信候補 1.2s の全 frame（等速・3 倍速化なし）③同区間の円クロップ sheet（CSS zoom 1.7・中心 37.5%/32.5%）を AI 目視

較正から得た事実：Kling の「バイザー越しの目」は 2.2s まで保持され、その後退色した（Q3 監査 README §3 を訂正済み）。

## 3. 判定ルール

- 配信候補区間の全 frame で §1 を満たして **PASS**。1 項目でも外れれば **NO-GO**（Try3 なし・追加生成なし）
- 候補区間は原本の等速 1.2s（29 frame）から選ぶ。3 倍速など時間圧縮は行わない。砲撃の弧が 1.2s に収まらない場合は「発射〜フラッシュ」を含む等速区間を優先し、収まらないこと自体を報告する
- 機械 PASS の後に、円クロップ sheet を keyvisual のポスターと並べて AI 目視し、CEO の目視に委ねる（機械 PASS ＝ 自動採用ではない）
