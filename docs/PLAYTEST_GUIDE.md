# SEVEN GODS プレイ説明書 ＆ テストプレイ手順（MVP Ver 0.1）

CEOが実際にプレイして感覚を確かめるための資料です。開発ログである
`docs/DECISIONS.md` とは別に、「遊び方」だけをまとめています。

---

## 1. ゲームの目的

7ラウンド以内に敵「試練の影」（HP 103）を撃破する**スコアアタック**です。

* 7ラウンド以内に倒せれば **勝利**
* 7ラウンドかけても倒せなければ **未撃破（敗北扱いだが、そこまでのスコアは残る）**
* 自分のHPが0になれば、その時点で即 **敗北**

「絶対に勝てる」ゲームではありません。守りすぎても攻めすぎても負けることがあります。

---

## 2. 画面の見方

| 場所 | 内容 |
| --- | --- |
| 上部バー | ラウンド数 / 7、神力（AP）現在値 / 上限、スコア |
| 左パネル | 敵のHPバーと「次の攻撃」の予告 |
| 中央パネル | 選んだ神・専属OTOMO・共鳴ゲージ |
| 右パネル | 自分のHPバー |
| ログ欄 | 直前の出来事（引いたカード、ダメージ、スコア変動など） |
| 手札 | 今使えるカード一覧。神力が足りないカードは薄く表示され選べません |
| 「ラウンドを終える」ボタン | このラウンドの行動を終えて敵の攻撃へ進む |

---

## 3. 1ラウンドの流れ

1. **ラウンド開始** … 神力が補充され（後述のとおり毎ラウンド増える）、ブロックがリセットされ、カードを2枚引きます（ラウンド1だけ最初から5枚）。同時に敵の「次の攻撃」が予告されます。
2. **あなたの番** … 手札から、神力の範囲内で好きな順・好きな枚数のカードを使います。全部使い切らなくても構いませんが、神力を余らせるとスコアが減点されます（後述）。
3. **「ラウンドを終える」を押す** … 予告されていた敵の攻撃を受けます。このラウンドに得たブロックがあれば軽減されます。
4. 次のラウンドへ進むか、7ラウンド終了／HP0で決着します。

**駆け引きの核心**：敵は次のラウンドに何をしてくるか事前に見せてくれます。それを見て「防御にAPを使うか」「無視して攻めきるか」を毎ラウンド判断するのがこのゲームの一番の面白さです。

---

## 4. 神力（AP）とカード

* 神力はラウンドごとに増えます：R1=2 → R2=3 → R3=4 → R4=5 → R5=6 → R6=7 → R7=8
* 神力は**その場で使い切り**が基本です。次ラウンドへの持ち越しはありません（余らせるとスコア減点）
* 手札上限は10枚。超えた分は自動で捨札に送られます
* 山札が尽きたら捨札をシャッフルして山札に戻します（今回のデッキは20枚なので、7ラウンドプレイしてもまず尽きません）

---

## 5. カードの6分類

| 種別 | 意味 |
| --- | --- |
| ⚔ 攻撃 | 敵にダメージ |
| 🛡 防御 | ブロックを得る（このラウンドの被ダメージを軽減） |
| ✨ 共鳴 | 共鳴ゲージを上げる |
| 🌿 支援 | HP回復や神力の追加取得など |
| 💀 妨害 | 敵の攻撃力を一定ラウンド下げる |
| 🌟 神託 | ダメージやスコアを大きく稼ぐ切り札枠 |

多くのカードは2種類の効果を組み合わせた「複合カード」です（例：攻撃しつつ共鳴も上げる、など）。

---

## 6. 共鳴ゲージ

選んだ神とのつながりを示すゲージです（最大7）。共鳴タイプのカードや、一部の攻撃・防御カードのおまけ効果で上昇します。

満タンになると**自動で発動**し、ゲージは0に戻ります。発動内容は**神ごとに異なります**（§8-2参照）。発動と同時にOTOMOも1段階成長します（精霊態→受肉態→童子）。

発動を強く意識して「今ためるか、先に攻めるか」を考えるのも一つの戦略です。

---

## 7. スコアの内訳

ゲーム終了画面に、以下5項目の内訳が表示されます。

| 項目 | 内容 |
| --- | --- |
| ダメージ | 与えた総ダメージ分そのまま加点 |
| コンボ | 1ラウンドに2枚目以降のカードを使うたびに加点 |
| 神力効率 | 神力を余らせると**減点**（無駄なく使うほど有利） |
| 撃破ボーナス | 敵を倒せた場合のみ。早く倒すほど大きい |
| 神託・共鳴 | 神託系カードや共鳴発動によるボーナス |

## 8. 神・デッキについて（決定24・25・26・27）

### 8-1. 神選択とデッキ構築

ゲーム開始前に、以下の流れで準備します。

1. **神選択画面**：七柱（恵比寿・大耀・蒼毘・才華・寿楽・福永・笑蓮）から1柱を選ぶ
2. **デッキ構築画面**：選んだ神で使えるカード（共通カード＋その神の専用カード4種）から、最初は「おすすめデッキ」（20枚）が自動で組まれた状態で表示される。＋/－で自由に調整でき、同じカードは2枚まで編成可能。20/20ちょうどでないとバトルを開始できません
3. 一度バトルを始めると、その神で次回選んだときにデッキ構築画面が**前回の編成**を覚えています（決定27。ブラウザのlocalStorageに保存。神を跨いだ複数保存はできず、直近1件のみ）

決着後は「同じ構成でもう一度」（同じ神・デッキで再戦）と「神・デッキを選び直す」の2択があります。

敵「試練の影」の攻撃力（予告される数値）：R1=5 → R2=6 → R3=8 → R4=9 → R5=11 → R6=13 → R7=15（自分のHPは30、敵HPは103）。

### 8-2. 七神の共鳴発動効果（決定23・26。今回検証してほしい数値）

共鳴ゲージが満タンになったときの自動発動効果です。恵比寿はこれまでの自動シミュレーターの基準値なので数値を変えていません。他6神は決定26のバランス調整でダメージを引き上げ済みですが、**自動シミュレーターでの検証のみで、人間のプレイでは未検証**です。

| 神 | モチーフ | 共鳴発動効果 | タグライン |
| --- | --- | --- | --- |
| 恵比寿 | 素朴に強い一撃 | 敵に25ダメージ、スコア+200 | 今日も上機嫌、明日はもっと大漁 |
| 大耀 | 豪快な高火力 | 敵に32ダメージ、スコア+170 | 退屈より、玉砕上等 |
| 蒼毘 | 攻めながら守る | 敵に21ダメージ、ブロック+15、スコア+170 | 誓いは違えぬ、盾となろう |
| 才華 | 手数とリソース | 敵に12ダメージ、カード2枚引く、神力+2、スコア+170 | 魅せてなんぼ、輝いてなんぼ |
| 寿楽 | 削って封じる | 敵に23ダメージ、敵の攻撃力を3ラウンド-4、スコア+170 | 長生きの秘訣？　楽しむことさ |
| 福永 | リスクと回復 | 敵に22ダメージ、HP+6回復、スコア+170 | 幸運は、待たずに掴みにいく |
| 笑蓮 | 支援特化 | 敵に21ダメージ、HP+10回復、ブロック+10、スコア+150 | 細かいことは、まあいいじゃない |

各神の専用カード4種（デッキ構築画面で「◯◯専用」と表示）も、この性格に沿った効果になっています。

## 9. テストプレイのやり方

### 起動
1. ターミナルで `npm run dev` を実行（すでに起動している場合は不要です）
2. ブラウザで表示されたURL（通常 `http://localhost:5173`。既に他のポートが使用中だと `5174` などにずれることがあります。ターミナルの表示に従ってください）を開く
3. 神選択画面が表示されるので、遊びたい神をクリック
4. デッキ構築画面が表示されるので、そのまま（おすすめデッキ）か調整して「この構成でバトル開始」

### プレイ（決定26の検証：7神バランスチェック）

決定26で他6神のバランスを自動シミュレーターだけで調整したため、**実際に人間がプレイした感触**を確かめたいのが今回の目的です。以下の進め方を推奨します。

1. **7神それぞれで最低1戦**、まずは「おすすめデッキ」のまま（+/-で調整せず）プレイしてみてください。神ごとの数値そのものの手応えを見るためです
2. 1戦は最後（勝利・敗北・未撃破のいずれか）まで通しでプレイしてください
3. 終了画面のスコア内訳を一度眺めてから、「同じ構成でもう一度」か「神・デッキを選び直す」で次の神へ
4. 余裕があれば、特定の神（気になった神）で3〜5戦繰り返し、「なるべく守りながら攻める」「防御を無視して攻めきる」などプレイスタイルを変えて試してみてください
5. 全部の神を一度に遊びきる必要はありません。何回かに分けて、気が向いたときに1〜2神ずつ試す形で構いません

## 10. フィードバックしてほしいポイント

プレイ後、以下について感覚を教えてください。次回のセッションでPlanner/Designerペルソナとして数値・演出に反映します。

**神ごとのバランス（決定26の検証。今回いちばん知りたいポイント）**
- [ ] 7神の中で、明らかに強い／弱いと感じた神はあったか（神の名前を教えてください）
- [ ] 各神の共鳴発動（§8-2）は、体感として強すぎる／弱すぎる／ちょうど良いか
- [ ] 各神の専用カード4枚の中で、強すぎる・弱すぎる・使いどころが分からなかったものはあったか
- [ ] おすすめデッキ（自動生成）の構成に違和感はなかったか（攻撃札が少ない／同じような効果ばかり、など）

**全体的な手応え**
- [ ] 難易度は？（簡単すぎる／ちょうど良い／難しすぎる）
- [ ] 何戦中何勝した？　どの神で、何ラウンド目で倒せたか
- [ ] 「敵の予告を見て守るか攻めるか」の読み合いは楽しかったか
- [ ] 共鳴ゲージの発動タイミングは狙って作れたか、それとも成り行きだったか
- [ ] デッキ構築画面（+/-操作・おすすめデッキ）は使いやすかったか
- [ ] UI・画面表示で分かりにくかった部分はあったか
- [ ] 1戦のプレイ時間の感覚（長い／短い／ちょうど良い）
- [ ] その他、気になった点・欲しい機能

### 伝え方
次回このプロジェクトを開くときに、上記について話していただければPM/Plannerペルソナが引き取って整理し、DECISIONS.mdに決定として記録した上で数値・演出に反映します。メモやスクリーンショットを残しておいてもらえると、より具体的な調整がしやすくなります。
