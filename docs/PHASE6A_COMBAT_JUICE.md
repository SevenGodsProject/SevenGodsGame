## 1. 何を作ったか

| 追加・変更 | 役割 |
|---|---|
| `combatTimeline.ts`（新規・純関数） | 1アクション分の GameEvent 列から「いつ・どこに・どの強さで着弾を見せるか」を決める**着弾計画**。数字・音・敵リアクション・表示HP・撃破演出がすべてこの計画を共有する（時刻の真実が1か所） |
| `visualHp.ts`（新規・純関数） | **表示HP**。`表示HP ＝ min(最大HP, 実HP ＋ まだ見せていないダメージ)`。着弾ごとに保留を解放する。回復・再開・想定外の減少は即時反映 |
| `useCombatPresentation.ts`（新規） | 演出の司令塔。着弾計画の作成、表示HPの追従、撃破／結果の順序、大きな一撃の画面揺れ（WAAPI）。**すべて `setTimeout` 起点＋安全弁**で、`animationend` に依存しない |
| `HpBar.tsx` | 主バーの後ろに**ゴースト**（直前HP、120ms 待って 340ms で追いつく）。回復時はゴーストが主バーの下に隠れるので不自然な帯が出ない |
| `EnemyPanel.tsx` | 被弾するのは**敵の立ち絵**（旧：HPバーのラッパーが揺れていた）。着弾の瞬間に対象だけ hit stop（ノックバック姿勢で静止）→ 段階別の揺れ＋閃光。ダメージ数字は立ち絵の胸の位置（HP の数値と重ならない）。HP 50%／25% 以下で静かな傷の色。撃破時の崩壊 |
| `PlayerPanel.tsx` | カードを使った瞬間に神が**構える**（cast 中の 280ms）→ commit で**突く**（26%＝90ms で最前＝着弾）。敵の通常攻撃は**敵の突進の最前**で被弾する |
| `useFloatingNumbers.ts` / `FloatingNumbers.tsx` | 数字を着弾計画の時刻で出す。段階別サイズ（16/22/30/40px）＋**最大クラス 52px**（神の一撃・最後の一撃）、⚡の追加ダメージは金色で少し遅れて出る。黒縁で立ち絵の上でも読める |
| `useBattleSound.ts` | 着弾音を着弾と同じ時刻に。勝利／敗北のスティング・ジングルは撃破演出・結果画面の時刻へ（**新規音源は追加していない**＝6-E の範囲） |
| `BattleResonanceCutin.tsx` / `BattleEnemyCutin.tsx` / `BattleScreen.tsx` | `animationend` を取りこぼしても必ず先へ進む**安全弁**（fallback タイマー）。共鳴 7/7 は**到達反応 200ms**を見せてからカットイン |
| `GameOverOverlay.tsx` | 「自己ベスト更新／あと◯点」を**勝利・スコアの後**に移動（勝利より先に不足を告げない） |
| `battle.css` | 上記の keyframes・変数。**向きの修正**：PC 幅では敵が左・神が右なのに、突進が相手と逆方向へ動いていた（`--atk-x/--atk-y` で相手の方向へ。390px では上下方向） |

## 5. Ghost HP / Hit Stop / 敵リアクション

- **Ghost HP**：着弾後に主バーが 180ms で縮み、直前HPの淡い帯が 120ms 待ってから 340ms で追いつく。**回復時はゴーストが主バーの下に隠れる**ため不自然な帯は出ない（実装・テストで確認）。表示HPは必ず最後に実HPへ一致する（背景タブで 60 秒遅延しても一致することをテスト）
- **Hit Stop**：対象要素（敵の立ち絵／自分側の被弾ラッパー）だけに掛ける。**ページ全体・root・global animation clock は止めない**。長さは L1 0／L2 20／L3 45／L4 60／神の一撃 80／最後の一撃 90ms
- **敵リアクション**：ノックバック（相手から離れる向き）→ 揺れ → 閃光。⚡の追加ダメージは**小さい金色の反応**で本体と区別。HP 50%／25% 以下で静かな傷の色（**常時点滅・激しい明滅はしない**）

## 6. 神の一撃・撃破・勝利遷移

```
共鳴7到達 → ゲージ発光（200ms）→ カットイン（900ms・結果は隠す）→ 溜め→突き（300ms）
 → 着弾：hit stop 80ms → 52px の数字 → 表示HP → 敵リアクション
 → 【非致死】通常進行へ／【致死】↓
 → フラッシュ → 崩壊（520ms）→ 「撃破」（850ms）→ 報酬 → 結果
```

- 致死時に**報酬が神の一撃より先に出ることは無くなった**（Before：報酬 1,325ms＜着弾 1,591ms／After：報酬 3,424ms＞着弾 1,950ms）
- **カード以外の撃破**（蒼毘「反撃の構え」など）も同じ順序を通る（Before は無演出で勝利していた）
- 旧実装にあった「報酬モーダルが 1 フレームだけ表示されてから消える」現象も解消（`rewardFirst == reward`）
- 勝利カードの順序：勝利 → 神域制覇 → ポートレート → スコア → **自己ベスト（更新／あと◯点）** → 記録類 → 内訳

## 10. Known Risks（6-A 時点）

1. **敵の突進の向きを修正した**（PC 幅で相手と逆方向に動いていた）。既存の演出と見え方が変わるため、CEO の実プレイで違和感がないか確認してほしい
2. ダメージ数字を立ち絵の上へ移した。密度の高い敵の絵の上でも読めるよう黒縁を足したが、**背景・敵によっては読みにくい組み合わせが残る可能性**がある（6-B の HUD 統合で名札化すると根本解決）
3. 神の一撃は**約 340ms 長くなった**（到達反応 200ms＋溜め）。テンポを壊さない範囲と判断したが、繰り返し見ると長く感じる可能性がある（定数 1 か所で調整可能）
4. 撃破演出で**敵の立ち絵が消える**ため、結果画面までの間に「相手の姿を確認できない」瞬間ができる（意図どおりだが好みが分かれうる）
5. Phase 6 監査の指摘のうち、**1366×768 で予告・敵HP が開始時に画面外**／**固定ボタンが手札に重なる**は 6-A の範囲外（6-B）
6. ヘッドレス Chromium での自動 QA のため、**手触り・音の評価は CEO の実プレイが必要**
7. 背景タブでは `setTimeout` が間引かれ、撃破演出が実時間で間延びする（進行は安全弁で必ず完了する。ゲーム結果には影響しない）
