## 5. Phase 5-C を実施すべきか

**今ではない。** 理由：

1. 神差38ptの原因は**受けの手段の有無**であって、専用カードの攻め性能ではない（§2-3）。
   福永に条件付き攻撃札を足しても、Ⅶの主砲290は受けられない
2. 5-A で分かったこと：**共有プールを触ると神差は縮み、専用を触ると広がる**。今の問題は「差を広げる」ではなく
   「下の神を上げる」で、それは専用札ではなく**受けの床**で解ける
3. 5-C は「攻めの個性」を足す施策として価値が残る。**A のあと**に、福永・大耀・蒼毘（対照）の3神パイロットで行う

## 6. 最小パイロット案（A：神託「加護」の再設計）

### 変更（データ＋効果1種）

| 項目 | 現在 | パイロット |
|---|---|---|
| 加護の託宣 | HP+30・ブロック+20 | **ブロック＝敵の予告ダメージの 50%（最低 20）**、HP回復は外す |
| 導きの託宣 | 1枚引き神力+1 | 変更なし |
| 天啓の託宣 | 敵に40 | 変更なし |
| 回数 | 通常7／神階4、1R1回 | 変更なし |

* 新しい効果 `kind: 'blockOfIntent'`（`ratio`・`min`）を1つ足す。`cardBonus.ts` の `incomingDamage` をそのまま使う
* 予告0（溜め）のときは最低値20だけ＝溜めラウンドに得をしない（`blocked` と同じ考え）
* 数値は `RULES.divination.guardRatio = 0.5` / `guardMin = 2` に集約（不変ルール4）
* 変えないもの：カード60枚、神階、敵、Passive、OTOMO、報酬、スコア式、BURST、`saveVersion`

### なぜ「神託」か

* 毎ラウンド**必ず**手に入る唯一の資源。手札運に依らない受けの床を作れるのはここだけ
* 「加護／導き／天啓のどれか」が**予告を見て決める判断**になる（今は作業）
* 福永・大耀（受け札が薄い）に最も効き、蒼毘・寿楽（既に受けを持つ）には効きにくい＝**神差を下から縮める**
* 機工師・魔獣の大技が「半分は必ず受けられる」ため、残り半分を手札で埋める問題になる＝理不尽から判断へ

### 受入基準（sim → 実プレイの順）

1. STAKE-01：全神階が 5-B 比 ±5pt、Ⅶ overall 45〜55%
2. 神階Ⅶ 神別 spread **38 → 30pt 以下**、福永・大耀の最良戦略 **+5pt 以上**
3. 神階Ⅶ 機工師・魔獣 **12〜13% → 25% 以上**、他5敵は ±8pt
4. bonus 成立・選択変更・BURST が 5-B 比 ±15%
5. 神託の選択分布：加護の使用率が「大技の予告ラウンドで 60% 以上、それ以外で 40% 以下」（作業ではなく判断になっている）
6. 実プレイ3戦（福永×機工師×Ⅴ、大耀×魔獣×Ⅴ、蒼毘×鬼将×Ⅶ）で、加護を「予告を見て」選ぶ場面が各戦1回以上
7. 既存テスト／tsc／lint／build PASS、`saveVersion` 不変

### 期待効果

受けの床ができることで、**5-A の「順番・予告を見て選ぶ」が守り側にも広がる**。
「予告を見た → 加護で半分 → 残りを手札で埋めるか、先に倒すか」が毎ラウンドの判断になる。
