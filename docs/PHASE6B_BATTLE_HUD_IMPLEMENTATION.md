## 1. 解いた問題（CEO 実プレイの指摘）

> 「カードが画面下部にあるため、カードを選ぶためにスクロールすると攻撃開始は見えるが、敵への着弾・被弾リアクションが画面外になって見えない」

原因は**構造**だった。戦闘画面は縦に 1,570px（PC）〜2,356px（390px）あり、
「敵が見える位置」と「手札を操作できる位置」が**排他**だった。CEO 環境（1508×660）では
手札まで **531px** スクロールが必要で、その位置での敵ポートレート可視率は **45%**、
390px では **0%**。Phase 6-A で作った着弾・撃破の演出は敵ポートレートの上で起きるため、
この排他がそのまま「Combat Juice が見えない」になっていた。

設計監査で B/C 案（`position: fixed` のドック）が失敗する理由も確定していた：
**固定要素はページの高さを減らさない**ため、アリーナ下部（敵 HP・予告・立ち絵）を
覆うだけで何も解決しない。よって採用したのは「**画面の高さに収める grid**」＝ D 案。

## 2. 実装した構造

```
┌─ app-header（戦闘中だけ 35〜40px に圧縮）────────────────────────
│ ┌─ .battle（grid-template-rows: auto minmax(0,1fr) auto）─────┐
│ │ [.battle-topbar]  ラウンド／神力／スコア              37〜43px │
│ │ ┌ .battle-main（1fr・可変・overflow: visible）──────────────┐ │
│ │ │  [敵名札]        [神名札]        [共鳴名札]                │ │
│ │ │  [敵立ち絵]      [神立ち絵]      [神技プレビュー]           │ │
│ │ │                                  [OTOMO立ち絵]             │ │
│ │ │  ← 3体とも同じ床ライン（align-items: flex-end ＋ 接地影）   │ │
│ │ └───────────────────────────────────────────────────────────┘ │
│ │ ┌ .battle-dock ────────────────────────────────────────────┐ │
│ │ │ [.divination-panel  加護／導き／天啓（横1列）]      56〜73px │ │
│ │ │ [.hand カード×n]              [ラウンドを終える／ログ]      │ │
│ │ └───────────────────────────────────────────────────────────┘ │
│ └───────────────────────────────────────────────────────────────┘
```

`body.battle-viewport`（BattleScreen のマウント中だけ付くクラス）で
アプリ外枠ごと「1画面モード」に切り替える。ホーム・デッキ構築・ランキングなど
他画面の CSS は一切変えていない。

## 9. 設計からの逸脱と理由（AI 判断）

| 設計 | 実装 | 理由 |
|---|---|---|
| アリーナ2列（左＝敵／右＝神＋OTOMO を縦積み） | **3列**（敵／神／共鳴・OTOMO）。`.ally-row` を `display: contents` にして DOM は無変更 | 縦積みだと右列の高さを共鳴・OTOMO パネル（固定分 150〜310px）に食われ、**神の立ち絵が 594px 環境で 64〜94px まで潰れる**ことを実測。3列にすると神もアリーナ全高を使え、敵:神 = 0.83〜0.87（設計 0.82）を全解像度で保てる |
| 390px も2列 | 390px も**3列**（同じ構造・寸法だけ変更） | 上と同じ。2列＋縦積みだと 390×696 で神の立ち絵が 77px、3列だと 196px |
| 神技プレビューは 1080p のみ全文 | **全解像度で1行ずつ表示**（はみ出しは省略記号）、`max-height: 600px` のみ非表示 | 「7に達したら何が起きるか」を常時見せる決定（8/31 P0-2）を落とさずに高さだけ詰められたため |
| 【型】と吹き出しは「アリーナが低い時（≤700px）だけ省略」 | **高さ ≤700px に加えて、幅 <900px でも省略**（【型】＋説明文） | 390px の列幅（≈126px）では説明文が4〜5行に折り返し、名札が 37px 高くなって敵＜神の逆転が起きることを実測 |
| 立ち絵オーラ（`::before`）はそのまま | 戦闘中だけ**回転アニメーションを停止**し、正方形を可変サイズに追従 | 回転する正方形の外接矩形は √2 倍になり、アリーナの下へ約 80px はみ出していた（`scrollHeight` を押し広げる）。blur 済みの conic-gradient なので静止しても見た目はほぼ同じ |
| sticky HUD（`.battle-hud`）は「390px では実装時に判断」 | **削除**（`BattleHud.tsx` ごと） | 名札が常時見えるため完全な二重表示。CSS・コンポーネントとも除去した |
